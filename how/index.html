See what your season tickets really cost

Paste one command into your terminal. Claude finds your ticket emails, works out every game you went to or resold, and builds this same site with your numbers. It runs on your computer, there's nothing to sign up for, and it works for any team in any sport.

  1. Get set up

    Install Node and Claude Code. Then connect Gmail at claude.ai → Settings → Connectors, and Claude Code picks it up.

  2. Run this

    It copies the site into a my-tickets folder and starts Claude.

    npx degit HansEngebretsen/krakentix my-tickets && cd my-tickets && claude "Read MAKE_YOUR_OWN.md and build my season ticket breakdown"

  3. Answer a few questions

    Your team, seats per game, your plan, and which seasons. Claude reads your emails, writes your data, checks the math, and opens your site at localhost. It also lists every game it had to guess, so you can fix those.

Just want to poke around?

This opens the site locally with Hans's data as the placeholder:

npx degit HansEngebretsen/krakentix my-tickets && cd my-tickets && npm install && npm run dev

What Claude looks for

  • Resale payouts from Ticketmaster, AXS, SeatGeek or StubHub
  • Your season invoice or payment plan, for what each game cost
  • Which games were in your plan, or your team's schedule

No Gmail?

Claude can also read your ticket account's sales history in Chrome. It can work from exports you drop into an inbox/ folder (a Google Takeout .mbox, CSVs or PDFs), or from emails you paste.

Your data

Your data stays in one file on your computer, data/tickets.json. Claude never writes seat numbers, order numbers or barcodes, and npm run check blocks them. Putting it online with GitHub Pages is optional, and Claude asks before doing it.
